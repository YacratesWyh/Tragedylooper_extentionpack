# oil-ui · 彩窗教堂 × 泥金抄本

**方向**：黄昏石造教堂里，被烛光照亮的一册泥金抄本。
夜石与深木是外壳，羊皮纸与金线是书页；rubric 红只标记"现在该做什么"，彩窗的宝石色只以低透明度光出现在页边和弹窗遮罩里。

**约束**：只改 `mod.css`，`index.html` / `app.js` 未动。
说明：该目录最初缺少 `index.html` 引用的 `layout.css` / `board.css` / `cards.css`，已按 `compare/gt-app/` 的 GT 基线原样补齐（内容未改，不属于本次设计改动）；其余 run 目录未触碰。

## 设计决策

1. **先收色位，再谈"古"。** 纸 3 阶（`#faf3e3 / #f0e3c8 / #e7d3a3`）、墨 2 阶、金 3 阶、rubric 红 2 阶、夜 1 阶；正文只用 ink / muted / rubric，金色退回边框与分隔线。彩窗的 lapis / ruby / emerald / amethyst 只以 0.05–0.12 透明度做页边光、题签光和遮罩，不参与文字色。
2. **题签居中，书页左对齐。** 顶栏下的题签改成书页式扉页构图：玫瑰窗饰 + 标题 + 金线居中，`放大版图` 绝对定位到右侧不参与居中；下方三栏保持左对齐。顶部是"封面"，下方是"摊开的书"。
3. **纸的质感用三层叠出来，不靠贴图。** 内联 SVG 噪声（约 5% overlay）+ 纸边径向渐隐 + 双线金框与分节金菱。书卷另加皮封面环、页边堆叠、书脊折缝与金叶角饰，保留书脊 / 纸面 / 金线 / 衬线 / rubric 的书籍身份。
4. **6 档字号。** 12 / 13 / 14 / 16 / 21 / 32px：正文 13–14px、行高 1.8–1.9；栏目标题 16px rubric + 金菱；扉页 32px；弹窗章题与元数据 21px。全页没有 11px 以下的正文。
5. **弹窗是另一页抄本。** 900px 的"对局笔记"排成两栏索引（身份推测 / 事件当事人推测），一屏看全；内衬细金框、蜡封关闭，页脚三个工具降为金线索引链接，只留"关闭"作主动作。快捷推理弹窗用深红页眉 + 蜡封，和纸面正文形成重量差。
6. **动效只做三处。** 烛光呼吸（阶段图钉）、弹窗翻页入场（位移 + 淡入）、卡片与按钮悬停抬升；`prefers-reduced-motion` 下全部关闭。

## 解决的可读性问题

- 原 `.desktop-note-scope`、`#desktopNoteStatus` 对比度 4.14:1 → 统一 `#6b5740`，纸面实测 **5.4:1**（`#faf3e3` 上 6.2:1）。
- 小字上提：状态行 / 日志 / 说明从 11–12.5px 到 **13px**，行高 1.8；`.action-card small` 10px → 12px。
- rubric 红 `#8a2f28` 在纸面 **6.56:1**；金色 `#9d7a37` 只有 3.13:1，因此只做边框/装饰，不承载正文。
- 去掉两处"彩色 2px 单侧边线"（当前操作面板、公开日志分组头），改为内框 + rubric 条；日志分组头改成整条 rubric 深红，不再用左侧色条。
- 弹窗内 `0 / 4000`、`本地保存`、"自动保存"等浅灰小字全部压到 `#6b5740` 以上。

## 验证

- `shot.png`：1440×900，默认状态。
- `dialog.png`：1440×900，点击 `#noteButton` 打开的"对局笔记"。
- `design_audit`（1280px）：**0 条对比度违规**；字号 6 档；非中性色 15 个。剩余两条 medium 建议：10 个间距值不在 4px 网格（多数来自 GT 基础层）、调色板 15 色（是纸/墨/金/红的功能色位，见第 1 条）。
- `oil_ui_shoot` 的"图片没加载出来"是误报：页面 24 个 `<img>` 的 URL 逐一请求均为 200。
- `▶` 被计为 emoji 图标：它是 DOM 原有的 U+25B6 播放符号，不能改文案，已保留并做成黄铜按钮。

## 自评

**30 / 35**（方向 6、构图 6、排版 6、色彩质感 6、完成度 6）。
扣分主要在：版图原画的信息密度很高，仍然抢走了一部分"书"的安静感；彩窗目前是气氛光而非结构元素，教堂感偏含蓄；左右两栏与书卷的下沿不齐，长页面的收束还能再讲究。
