## 方向

一句话：**三卷书摊在烛光石室里的一张长桌上**——中央是摊开的彩窗图册，左右是规则册与编年史；彩窗只做墙上的光，纸面、金线与朱红承载全部内容。不是深色 dashboard，而是一本被烛光照亮的书。

## 六条设计决策

### 1. 材料先行：先决定"这是纸、是皮、是金线"，再谈布局
- 中央对开本：`7px` 皮革封边 + `1px` 金线 + 页缘叠层 + 中缝阴影（`.play-area` 的 box-shadow 与 background）；书脊顶部保留朱红书签带。
- 两翼是合着的两册：朝书心的一侧用 `repeating-linear-gradient` 画出 8px 纸口（一排排纸边线）+ 内阴影，外缘单线金框；这样左右两栏不再像两张卡片。
- 纸纹：内联 SVG `feTurbulence` 噪声（data URI，无外链）以 multiply 叠在纸色上，纸面有纤维感但不脏。
- 全部质感只用 CSS/内联 SVG，没有新增图片、没有外部字体/网络资源。

### 2. 字体：宋体正文 + 可选的明朝题签
- 正文、按钮、日志、输入统一为 `Noto Serif SC`（本机可变字重，Windows 已装）；题签仍走 `--loop-title-font`（「题签与字体」里可切换，未破坏该交互），卷首题名 33px / `.15em` 字距。
- 收敛成 **6 级字号**：12（说明/注）、13（正文）、15（分节题）、17（版图眉题）、21（数值与弹窗题）、33（卷首题名）。正文不小于 13px。
- 旧图层遗留在导航、日志、推理行上的黑体会被我统一收回到衬线（`!important` 只用于 `font-family` 这一属性）。

### 3. 配色：一个地面、一种纸、一种墨、朱红与金；彩窗色只做语义色
- 纸 `#f3e7cb`、纸高光 `#faf1dc`、墨 `#2b2016`、次墨 `#57452f`、朱红 `#7a2b26`、金线 `#b08a4a`、暗金 `#8a5f2a`、石墙 `#120c09`。
- 金只用于线与饰；**金色文字**统一用 `#6b5122`（纸上 5.2:1）。纸面正文 12.7:1，朱红标题 7.6:1，深色底上的米色文字 9–12:1。
- 彩窗的蓝绿/玫瑰/紫只留给语义：友好/密谋/不安、阶段色、窗光。

### 4. 层次：抄本的眉题 + 手稿的行
- 每个分节标题 = 金菱 + 朱红小标 + 收束金线；去掉了主题里"彩色左边条 + 灰底卡片"的 dashboard 痕迹。
- 侧栏推理表从一只只盒子改成**手稿行**（金线分行、芯片做成纸面小印）；`当前操作` 用一片极薄的朱砂色代替彩色侧边条。
- 分类色只用于状态芯片（可能=橄榄、排除=赭、怀疑=朱红），不再用彩色标签铺底。

### 5. 构图：三叶祭坛画
- 三列共享顶线，中央最重；两侧书叶在桌面端 `sticky` 贴住视口（内部可滚动），长页滚动时只有图册前进，任何滚动位置都不会出现"孤零零一张卡片"。
- 版图 = 四块**裱在纸上的彩窗图版**：7px 纸边 + 1px 金线 + 接触阴影；行动牌 = 摊在纸上的塔罗小牌（66px 宽、注音完整、悬停抬起 2px）。
- 卷首：玫瑰花窗 + 题名 + 一条渐隐金线；右侧一枚 3% 的玫瑰窗光影，当作"墙上的光"，不抢正文。

### 6. 动效：纸页落下、牌面抬起、烛光呼吸
- 弹窗 300ms 落纸（`tc-leaf-in`）；牌/角色卡悬停 `-2px`；彩窗 9s 明暗呼吸；`prefers-reduced-motion` 与「关动态」下全部关闭。所有动效只改 transform/opacity。

- 大图预览里 app.js 写死的 `../live-assets/...` 在本层目录 404：用 CSS `content:url()` 接回真实的 `../../live-assets/...`（不改 DOM、不改 src，仅在预览层修复显示）。

## 已知取舍（不打算"修"的）

- **渐变 8 处 / 重阴影 12 处**：这是纸、皮革、书脊、页缘的物理层（书在桌上，不是浮起的卡片），不是 dashboard 的发光卡片。工具按"页面"规则判 FAIL，本题材保留，并已在上面说明用途。
- **`no-title`**：页面的 `h1` 在 `.loop-intro`（界面层在 `<main>` 之前生成的卷首），不在 `<main>` 里；BRIEF 禁止改 DOM，无法搬进画布。
- **ragged-row 476px**：两侧书叶是 sticky 的视口高侧栏，中央图册更长——这是"书 + 边栏"的构图，不是同排卡片不齐。
- **27 种非中性色**：羊皮纸的明暗层次 + 语义色叠加，超过工具建议的 8 色；这是抄本材料的代价，不做"一色极简"。
- `#musicToggle` 的 ▶ 是 fixture 自带的文字字形，不是 emoji，保留。
