# palate · 书卷教堂（夜祷抄本）

只改了 `mod.css`：`index.html` / `app.js` 一个字没动，没有外部网络资源，纹样全部是内联 SVG data URI。

**北极星**：一本摊在石制讲坛上的泥金抄本。两侧彩窗漏进冷光，只有书页被烛光照亮，界面本身退到阴影里——剩下的只有纸、金线、朱红 rubric 和衬线字。

---

## 设计决策

### 1. 配色：一条暖中性阶，彩窗只当"光"用
墨 `#2e2620` / 纸 `#f3e9d6` / 金 `#a07f42` / rubric 朱红 `#8a3138`，再加三块玻璃色（青 `#42626e`、玫瑰 `#8c4756`、紫 `#5c4669`）。玻璃色**只出现在"光"和语义**里：页眉右端一块极淡的圆窗、书页顶部的两侧冷光、以及推理标记（✓ 青绿 / × 赭红 / ? 金黄）和日志 token。原来日志 token 是霓虹粉 `#ff7ac8`、霓虹紫 `#c996ff`，阶段色也是一组霓虹，在烛光纸上像 dashboard 漏进来的指示灯，全部降成玻璃色。

### 2. 字体：全站衬线，六级字号
`Noto Serif SC / 思源宋 / Songti SC / Yu Mincho / SimSun → Georgia`。字号只有 13 / 14 / 15 / 17 / 22 / 26 六档（design_audit 现在报的就是这六档）。章节标题 h2 统一成 rubric 体例：朱红、`.14em` 字距、前面一枚 6px 金菱花；弹窗标题 22px，书名 26px。数字用 `tabular-nums`，日志时间戳走 Georgia 小型大写。

### 3. 层次：书是主角，其余退后
- 书（`.play-area`）：书脊折痕（沿用 `--loop-spine`）、左右鎏金页边（金-奶白-金的 3px 钉口）、版心细金线内框、底部中缝一枚朱红书签丝带；顶部一道烛光渐变，两侧各落一点彩窗冷光。
- 左右两页：纸色 + 5px 内嵌细金线；章节之间不是灰分割线，而是「两端收尖 + 中间金菱」的抄本饰线。
- **当前阶段**做成讲坛卷带：朱红底 + 内金线，是整页唯一的强饱和块，一眼锁定"现在轮到谁"。
- 主操作 = 朱印（朱红渐变 + 内金线），次操作 = 米色纸 + 金线；投降只描朱红边，不抢主操作。

### 4. 质感：纸纤维、卷草角饰、原画统一
- 纸纤维是 172px 的 `feTurbulence` 噪点（13% 不透明）平铺，叠在纸色渐变上，100% 缩放下能看见纤维。
- 弹窗 = 泥金标题页：双金框（`border` + `outline` 5px 偏移）、两角卷草（同一张 44px SVG，右下旋转 180° 复用）、衬线 22px 朱红标题。
- 版图四块场地各加一层"顶光 + 底部收暗"，把四张风格不一的游戏原画统一成"被烛光照到的插图"；角色卡改成米色卡纸 + 细金框，像钉在版图上的小圣像。
- 行动牌从深色面板里救出来：改成**摊在纸上的卡纸**（米色卡纸 + 细金框 + 13px 衬线标签），`flex:1 1 0` 均分卡座，八张牌不会把最后一张切在边上。

### 5. 动效：只留三处
书页"落定"（0.62s，位移 6px + 微缩放）、弹窗入场（0.26s）、hover 抬升 2px。全部 `prefers-reduced-motion` 关闭。没有循环动画——截图取证时不会抓到半透明的中间态。

### 6. 可读性修复（硬性）
| 问题 | 原来 | 现在 |
| --- | --- | --- |
| `.desktop-note-scope` / `#desktopNoteStatus` | 4.14:1，低于 AA | `#5c5044`，6.4:1 |
| 正文小字 | 10 / 11 / 12px（action-card 标签、chip、日志时间、meta label、按钮） | 一律 ≥13px，正文 14px |
| 笔记弹窗里的 `0 / 4000` | 继承深色主题 `--accent`，在纸上约 2:1 | 朱红 rubric + `tabular-nums` |
| 日志 token 对比 | 霓虹粉/紫在纸上发飘 | 玻璃色（青绿 5.8:1 / 赭石 5.1:1 / 紫 6.3:1） |
| 行高 | 1.55–1.65 | 正文 1.75–1.9 |
| 焦点态 | 部分控件无 | 统一 2px 金/rubric 描边，offset 3px |

`design_audit` 现在**没有对比度问题**。

## 实现备忘

- 选择器统一写成 `:is(.loop-ui, body) …`：GT 图层与预览壳带 `.loop-ui` 时按原样命中，不带壳直接开 HTML 时也能落到页面上；优先级与 `.loop-ui X` 相同，所以对主题的覆盖关系不变。
- 装饰只用了这些未被占用的伪元素：`body::after`（四角压暗）、`header::after`（圆窗）、`.side-panel::before` / `section+section::before`（版心线与饰线）、`.play-area::before/::after`（重绘原有的两道）、`.location::after`（顶光）、`h2::before`（金菱）、`.choice-dialog::before/::after`（角饰）。没有新增元素，没有改文案。
- 已知取舍：左栏内容比版图短，整页截图时下方会留一块石地（1440×900 首屏不受影响）；角色卡与版图原画是游戏素材，色调偏暗，只用金框与顶光去统一，没有覆写原画。
