# 六组设计对比（v2）说明

## 目的

在同一个"独立页面"上比较四种前端设计插件风格与基线，产出可量化的视觉结论，用于决定 GT v3.2 的整合方向。

## 方法

- **同一对象**：`compare/runs2/<方案>/index.html` 是一份完整复刻《惨剧轮回》界面与交互的静态页面（含 `app.js`：角色卡点击、笔记弹窗、行动牌选中、快捷键）。
- **只准改外观**：每个方案只能新增/修改 `mod.css`，禁止改动 `index.html` 与 `app.js`；DOM、类名、事件全部原样保留。
- **统一渲染**：1440×900 视口、同一浏览器、同一本地服务；每个方案提交首屏截图 + 打开"对局笔记"弹窗的截图。
- **评分维度**（各 7 分，满分 35）：视觉完成度 / 书卷教堂身份 / 系统一致性 / 可读性 / 功能完整与保留。

## 结果

| 名次 | 方案 | 分数 | 关键特征 |
|---|---|---|---|
| 1 | taste | 30.5 | 皮革封边 + 页缘叠层；版图做成裱在纸上的彩窗图版；行动牌像塔罗小牌 |
| 2 | oil-ui | 30 | 居中扉页 + 玫瑰窗饰；有限色位；笔记弹窗两栏索引，蜡封关闭 |
| 3 | palate | 30 | 泥金抄本 + 讲坛卷带；纸纤维；章节饰线为收尖 + 金菱 |
| 4 | GT v3.1.1 | 29.5 | 烛光暖棕底 + 陈酒红/旧金；打开角色卡只轻压暗背景 |
| 5 | vanilla | 22 | 原站原生深色 dashboard：可用、无身份，存在 1.73:1 对比度问题 |
| 6 | design | 19 | 半成品：右栏文字对比度严重不足，缺交付说明 |

## 结论

1. 三家插件方向（taste / oil-ui / palate）都稳定达到"成书"级别，且都修复了原站 4.14:1 的可读性问题；
2. 差异在气质而非质量：taste 偏装帧实物、oil-ui 偏扉页版式、palate 偏讲坛抄本；
3. 共同有效的手法：一条暖中性阶 + 单一强调色、纸纹与金线、章节 rubric 体例、把深色动画图版统一进纸面；
4. 下一版 GT 建议合成：taste 的封边/页缘 + oil-ui 的扉页版式 + palate 的纸纤维与卡片处理。

## 复现

页面基线在 `runs2/` 各目录（`index.html` + `app.js` + 基础 CSS）；各方案的 `mod.css` 直接叠加即可复现截图。
完整报告见 `reports/report2.html`，截图见 `reports/shots/`。
