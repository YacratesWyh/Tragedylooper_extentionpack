# 对比任务 v2 · 书卷教堂 UI（独立页面）

## 对象
`compare/runs2/<你的名字>/index.html` 是一个已完整实现的静态页面（含 `app.js` 交互、`app.css` 页面补丁、GT 基础图层）。
它复刻了《惨剧轮回》整站前端：顶部导航、左栏对战控制/当前操作/对局笔记、中央书卷版图 + 行动牌、右栏公开信息/特殊规则/公开日志，以及笔记/快捷推理/轮限牌等弹窗。

## 你的任务
只允许**新增/修改 `mod.css`**（以及必要时在你目录内新增本地图片/CSS，但不要引用外网）。
**禁止**修改 `index.html` 和 `app.js`：DOM、类名、事件、交互必须原样保留。
目标：把现有界面按“彩窗教堂 + 泥金抄本 + 意大利教堂/博物馆氛围 + Manosaba/Madoka 影响”的方向做出有品位的视觉提升，
必须保留书籍身份（书脊、纸面、金线、rubric 红、衬线字体），并保证可读性（文字对比 WCAG AA，正文 ≥13px）。

## 你必须做的验证
1. 用 `oil_ui_shoot` 截 `compare/runs2/<你的名字>/index.html`（本地服务 `http://127.0.0.1:8765/`），尺寸 1440x900，截图存到你目录 `shot.png`；
2. 打开一个弹窗（点角色卡或 `#noteButton`）再截一张 `dialog.png`；
3. 用 `design_audit` 检查你的页面，修掉硬性对比度问题；
4. 在目录里写 `NOTES.md`：3–6 条设计决策（配色/字体/层次/质感/动效），以及你解决的可读性问题。

## 约束
- 不改交互、不改文案、不改 DOM 结构；
- 不引入外部网络资源；
- 只用 CSS（允许 CSS 自定义属性、伪元素、渐变、纹理、阴影、动画）；
- 别把页面做成深色后台：这是“被烛光照亮的书”，不是 dashboard。

完成后回报：目录、`shot.png` 路径、`dialog.png` 路径、NOTES.md 摘要。
